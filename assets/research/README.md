# Future research photographs

The live portfolio currently displays a clearly labeled conceptual SVG diagram instead of laboratory photographs.

When you have photos approved for public sharing:
1. Put the photos in this folder, for example `robot-setup.webp`, `tunnel.webp`, `fusion-360-cover.webp`.
2. Open `index.html` and locate the `upcoming-photo` section just after `research-track`.
3. Replace that notice with image elements using paths like `./assets/research/robot-setup.webp` and meaningful `alt` descriptions.
4. Commit changes to GitHub; GitHub Pages will redeploy automatically.

Do not publish unreleased lab figures, experiments, or manuscripts without permission from the lab supervisor.
