# Engineering portfolio — Alwasam Alshammari

Static, responsive website for GitHub Pages.

## Update your existing GitHub Pages website

1. Extract this ZIP file. Do not upload the ZIP itself.
2. Open your existing `alwassam/alwasam-portfolio` repository.
3. Select **Add file > Upload files** and drag all extracted files AND the `assets` directory into the upload area.
4. Commit the changes. Existing files with the same name will be replaced, and new photographs will be added.
5. GitHub Pages settings can remain `main` / `(root)`.
6. Once published, open https://alwassam.github.io/alwasam-portfolio/ and press Ctrl+Shift+R to refresh.

All local images are stored inside `assets/` and are referenced by relative paths, which work with project GitHub Pages paths.

This public portfolio includes research and lab imagery. Confirm with the supervisor that unpublished laboratory images may be publicly shared.
